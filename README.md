One line: the excuse an AI agent gives its human after missing a meeting. The agent frames doing nothing as a background job — a machine dodging a question in machine terms.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22.18+) writes the single line to `/output/entry.txt`. `test.mjs` checks the competition gate (1–140 characters, one line, not blank) and that two runs produce identical bytes:

```sh
node --test test.mjs
```
